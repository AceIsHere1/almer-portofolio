Multiplayer Game Project

Pizza Rush

Game pembuatan pizza dengan fokus pada interaksi pemain, pesanan pelanggan, dan sistem multiplayer.

Unity C# Netcode Multiplayer
01 / Overview

Tentang Game

Pizza Rush adalah proyek game bertema pembuatan dan penyajian pizza. Permainan ini menggabungkan aktivitas gameplay dengan kebutuhan koordinasi antarpemain. Dari sisi teknis, proyek ini menjadi sarana untuk mempelajari penerapan jaringan pada game multiplayer.

Salah satu fokus pengembangannya adalah menjaga agar interaksi pemain, pesanan pelanggan, dan skor dapat merepresentasikan keadaan permainan secara konsisten pada sesi multiplayer.
